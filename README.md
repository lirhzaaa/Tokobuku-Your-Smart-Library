# Tokobuku - Your Smart Library

Tokobuku is a full-stack web application built with the MERN stack for managing and selling books online. The platform supports user and admin authentication, persistent shopping carts, secure transactions, and complete content management features.

## 📌 Description

Tokobuku provides an online book store experience with features such as book browsing, cart management, and secure checkout. Users must register and activate their account via email before accessing the platform. Each user has a persistent cart stored in the database, ensuring cart data remains available across sessions.

Admins can manage books, categories, banners, blogs, orders, and transactions through a dedicated admin system.

## ✨ Main Features

### User

* Account registration with email activation
* Login using JWT authentication
* Browse books by category
* Persistent shopping cart per user
* Place orders and complete transactions
* Secure payment via Midtrans

### Admin

* Manage books and categories
* Manage banners and blog content
* View and manage orders & transactions
* Role-based access control
